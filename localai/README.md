# Kira Local

Локальное приложение для работы с ИИ-моделями на вашем компьютере.

1. **Модели** (левая шторка) — скачивайте модели с Hugging Face, из GitHub Releases или по прямой ссылке; можно подключить свой сервер (Ollama, LM Studio).
2. **Чат** — основной экран; работает с загруженной текстовой моделью (GGUF через `llama-server`), ответы стримятся.
3. **Студия** (правая шторка) — вкладка **Код** (отдельная code-модель со своим слотом) и вкладка **Изображения** (генерация через diffusers).

## Запуск

```bash
pip install -r requirements.txt
python -m kira_local            # http://127.0.0.1:8765
```

- Для GGUF-моделей нужен [llama.cpp](https://github.com/ggml-org/llama.cpp/releases): `llama-server` в `PATH` или `LLAMA_SERVER_BIN=/путь/llama-server`. Альтернатива без установки — вкладка «Свой сервер» (Ollama и др.).
- Для изображений: `pip install diffusers torch transformers accelerate safetensors`; скачайте diffusers-репозиторий (с `model_index.json`) или `.safetensors` чекпойнт.
- Файлы хранятся в `~/.kira-local` (`KIRA_LOCAL_DIR` меняет путь). Токен HF — поле в UI или `HF_TOKEN`.
- Сервер слушает только `127.0.0.1` — не открывайте его в сеть без авторизации.

Тесты: `pip install pytest pytest-asyncio && pytest`.

## Android (APK)

Папка `android/` — приложение, которое запускает модели **прямо на телефоне**: тот же интерфейс (`web/`), локальный сервер на Java (`android/core`) и `llama-server` (llama.cpp), собранный под arm64.

APK собирает **Codemagic** (`codemagic.yaml`, инструкция — [CODEMAGIC.md](CODEMAGIC.md)) или GitHub Actions (`.github/workflows/android.yml`): откройте вкладку **Actions → Android APK → последний запуск → Artifacts → KiraLocal-apk**, скачайте, распакуйте zip и установите `KiraLocal.apk` (разрешите установку из неизвестных источников). Запуск вручную: Actions → Android APK → Run workflow. Тег `kira-local-v1.0` прикрепляет APK к релизу.

Заметки: нужен arm64-телефон (2018+), 6 ГБ ОЗУ и более комфортны для 3–7B моделей (квант Q4_K_M); модели хранятся в памяти приложения (`Android/data/dev.kira.local/files/models`). Генерация изображений на телефоне пока недоступна; используйте «Свой сервер» (Ollama и др.) для моделей любого формата.

## Изображения

Вкладка **Студия → Изображения**: стили и форматы одним нажатием, 1–4 варианта за раз, прогресс и кнопка «Стоп», «Улучшить промпт» (перепишет идею в подробный промпт через запущенную текстовую модель), seed и повтор настроек, галерея всех картинок с параметрами.

- **ПК:** локальная генерация через diffusers (`pip install diffusers torch transformers accelerate safetensors`).
- **ПК и телефон:** подключите внешний сервер во вкладке «Модели → Свой сервер» (тип «изображения»): AUTOMATIC1111 / Forge / SD.Next (запуск с `--api`) или OpenAI-совместимый `/v1/images/generations`. На телефоне это основной способ.

В чате добавились кнопки «Стоп», «Повторить» и «Копировать».

## Дизайн и аккаунты

Интерфейс в монохромном стиле «learn up»: чёрные волнистые шапки, белые карточки с жёсткой рамкой, чёрные кнопки, круговой индикатор загрузки; есть светлая и тёмная темы (Профиль → Оформление).

- **Онбординг → подключение аккаунтов.** Вставьте токен Hugging Face и/или GitHub — он проверяется и хранится только на устройстве. Что даёт подключение: доступ к закрытым (gated) моделям, более высокие лимиты запросов, ваши лайки HF и звёзды GitHub на главной.
- **Поиск.** Hugging Face (фильтры: GGUF, текст, код, картинки, речь; сортировка: популярные, в тренде, новые, по лайкам) и GitHub (по темам LLM, GGUF, диффузия, речь). Ссылку на репозиторий или файл можно вставить прямо в строку поиска — откроется разбор модели.
- **Карточка модели.** Семейство, размер, параметры, контекст, лицензия, можно ли запустить; выбор квантизации; круговой индикатор загрузки.
- **Библиотека.** Запуск/выгрузка, тест скорости (ток/с), избранное, статистика.
- **Чат:** роли, креативность и лимит ответа, прикрепление текстовых файлов, голосовой ввод (если поддерживает браузер), библиотека промптов, стоп/повтор.

Тесты интерфейсной логики: `node --test tests/analyze.test.js tests/hub.test.js`.

## Ещё

- **Markdown в ответах:** заголовки, списки, цитаты, **жирный**, *курсив*, `код`, ссылки (безопасная сборка DOM без innerHTML).
- **Дуэль моделей:** один вопрос двум моделям (слоты «Чат» и «Код») — ответы и скорость рядом, голосование и таблица побед.
- **Поиск по чатам**, кнопка «Продолжить с последней моделью» на главной.
- **Проверка места на диске** перед скачиванием (и на ПК, и на телефоне).

## Безопасность и надёжность

- Настольный сервер принимает запросы только с `localhost` (защита от DNS-rebinding) и отвергает чужой `Origin` у изменяющих запросов (CSRF). При запуске с `--host 0.0.0.0` проверки отключаются и выводится предупреждение — авторизации нет.
- Android: доступ к встроенному серверу только по одноразовому токену (cookie).
- Идентификатор модели детерминирован (источник + набор файлов): повторное нажатие «Скачать» продолжает прерванную загрузку, а установленную модель второй раз скачать нельзя.
- Если запуск модели не удался, слот не остаётся в «полузагруженном» состоянии.
- Android: окно выбора файла для чата и кнопка «Скачать» у картинок (Pictures/KiraLocal) работают в WebView.
- Диагностика (Профиль → «Проверить приложение и сеть»): llama.cpp, диск, память, связь с HF/GitHub и остаток лимита GitHub API.
- Дымовой тест интерфейса: `python tests/ui_smoke.py http://127.0.0.1:8765` (нужен playwright).
